# Binder

This folder contains a **Binder** knowledge base: short, operational guidance written in Markdown with machine-readable frontmatter.

## Common commands

- `binder validate .`
- `binder build-index . --apply` (or `--check` in CI)
- `binder new . --domain <domain> --id <kebab-id> --title "<Title>" --tag <tag> --owner <owner>`
